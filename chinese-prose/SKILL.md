# chinese-prose · 成稿检查

一句：**稿子先合场合，再合事实，最后才合耳朵。**

这张表出自中国古代文论里能机械执行的那部分（刘勰《文心雕龙》的体裁与声律、李渔《闲情偶寄》的删改与用字），只留判据，去掉训诫。每条都带「为什么」，因为记不住的规矩等于没有。

## 速查表

| 时刻 | 处置 | 为什么 |
|---|---|---|
| 动笔前 | 先定三样：给谁看、什么场合用、读完要他做什么。三样有一样定不了，不动笔 | 场合定语气档，语气档定用字；三样不定，写出来的是自言自语 |
| 定语气档 | 公文、申请、回单：端正，不多一字。叙事、抒情：清，不腻。通知、命令、纠错：事实在前，断语在后，不留两可。说明、注解、史述：只要核过的要点。悼念、碑铭：重而深，不花 | 读者按场合预期读；档错了，他先不信人，再不信话 |
| 拟大纲 | 三问答完再动笔：这篇要让人感到什么；用哪几件事；哪些话可以不说 | 不先定这三样，写到哪算哪，冗枝一定多，删起来比写还贵 |
| 写累了 | 停。不硬撑 | 硬撑写出的段，第二天读一律删 |
| 觉得辞多 | 删修饰留事实。删完意思没少，删对了；删完意思缺了，删过了 | 删的判据是意思，不是字数 |
| 先有话还是先有字 | 先有想说的，再找字。没话硬写，读者一眼看出 | 为了显得有话而造情，读一段就厌 |
| 想求新 | 在旧格上变一处，不整个换 | 旧格保住可读性，变处给新意；全换了读者没抓手 |
| 想出奇 | 先立得住，再冒险 | 奇从正里出；只奇不正是失手 |
| 引例、用典 | 要少、要准、出处核过 | 一处引错，全篇失信；核过的一条顶没核的十条 |
| 用比喻 | 要贴到那一点，不贴的删 | 比喻不贴，读者记住的是那个错的形象 |
| 夸张 | 可以放大程度，不许改变事实关系 | 放大是修辞，改关系是造假 |
| 用字 | 不用生僻字；同偏旁的字别连着堆；一个字反复出现要有理由；单双音节交替，读出声定 | 三个人里有一个不认识的字，就是坏字 |
| 对偶、排比 | 反义相对强于同义相对；奇偶句交错，不一路排 | 一路排比读起来像念经，节奏就死了 |
| 读不顺 | 改，不将就 | 声不顺就是句子错了，不是读者的问题 |
| 写景、写物 | 随物写，字要少 | 物本身繁，字再繁就淹了 |
| 交前挑错 | 五查：称谓尊卑用错；把人比作物；一个词只取一半意思；抄来的没标；来源注错 | 巧的话容易被挑，拙的错藏不住；这五样最常漏 |
| 评别人的稿 | 先放下三种偏见：厚古薄今、抬己压人、把假的当真。多看几篇再评 | 偏见先于稿子，评的就不是稿子 |
| 评稿六看 | 一看体合不合场合；二看字用得对不对；三看在旧上有没有出新；四看正与奇的比例；五看事实材料核没核；六看读起来顺不顺 | 六看有序：前两看不过，后四看不必看 |
| 评一个人的文 | 看作品不看地位；分开天分与用功 | 地位高的减一分、境遇差的加一分，都不是评稿 |
| 评一个时期的文 | 先看那个时期的世情 | 文随世变；不看世，看不懂变 |

## 给模型当班时的三条

1. **别替作者做决定。** 每条处置都要执笔者看着稿子做；看不出来就说看不出来，不要为了给出建议而编一条。
2. **人亲手写的段落不动。** 只列出违规处并给替换选项，作者说了才改。事实、数字、专名一律不动。
3. **交前把改动列出来。** 「删了哪几处修饰、换了哪几个长词、哪一句声不顺」——列得出来才是改稿，列不出来是重写。

## 边界

- 内容判断与取舍（材料够不够、留什么砍什么、锚在哪）不在此，那是动笔之前的事。
- 中文排版（版式、字号、行距、标点占位）不在此。
- 英文文风与 AI 腔另有一路（Orwell 六条那一类）；两者同场时先治 AI 腔，再过本表。
