# script-check · 剧本检查

一句：**一场戏为一个人的一件事而写，其余都是陪衬；陪衬不为那件事服务就删。**

条目出自中国古典戏曲论里能机械执行的那部分（李渔《闲情偶寄·词曲部》的结构与词采），只留判据。它管的是纸上的戏成不成立，不管拍得好不好看。

## 速查表

| 时刻 | 处置 | 为什么 |
|---|---|---|
| 开稿 | 先写出「这一人、这一事」一句。写不出，不铺 | 没有这一句，每一场都像主线，全篇散成一堆珠子 |
| 加人物 | 多一个人只为多一件事；事可以换人，人不可以为了凑而加 | 头绪多是剧本第一大病；人物加到第三个以后，观众记不住谁是谁 |
| 加支线 | 不为主线服务的支线删，再精彩也删 | 支线精彩是它自己的事，不是这部戏的事 |
| 写这一场 | 前看几场、后看几场：有名有姓的人、提过的事、说过的话，都要有落点 | 一处漏，整部戏破；宁可想到不用，不可用了没想到 |
| 埋伏笔 | 埋的必回收，回收的必有埋 | 只埋不收是欠账，只收不埋是作弊 |
| 情节 | 别人写过的不用；荒唐的不用；写古事就古到底，写今事就今到底，不混 | 观众没看先知，就不看了；虚实混了，两头都不信 |
| 对白 | 八查：读出声要响；像那个人说的，先替他想再替他说；该长长该短短；干净，不带书卷气；有新意；少方言；观众听一遍要懂，要想才懂的句子不是好句；前后不漏（时间、地点、称谓、道具、谁知道什么） | 对白和情节同等重要；情节好对白差，戏在台上就塌 |
| 堆典故人名成句 | 删 | 观众听不出典故，只听出作者在炫 |
| 开场 | 直入，不绕帽子；开头几句定全篇调子；主角早出场 | 开场绕，观众等；主角晚，观众押错人 |
| 中段 | 收一次口：上半段要有一个小结，让人能停也想继续 | 一条线拉到底没有节，观众中途累 |
| 结尾 | 要热，不要冷收；前面埋的在这里一并收 | 冷收观众带着没落的地方走，记住的是缺 |
| 插科打诨、闲笔 | 与主线有关的才留；不淫不俗；自然生出，不硬塞 | 闲笔是提神的，硬塞的闲笔提不了神只打断 |
| 旧本翻新 | 骨架不动，只换皮：观众未看先知的桥段整段换，其余不动 | 动骨架是另写一部，不叫翻新 |
| 长改短 | 删关目，保节奏；删掉的关目在前后场要补上落点 | 只删不补，伏笔就悬空 |
| 写完 | 问这一场怎么演。演不出来的不算写完 | 剧本是给台上用的，不是给案头看的 |
| 预告结局 | 不预告；下一步只写眼前这一步的意外 | 观众先知即无戏 |

## 判一份别人的剧本时

按序问，前面不过后面不必问：

1. 这一人、这一事是哪一句？作者写得出来吗？
2. 去掉哪一个人物，故事仍然成立？成立的那个就是多的。
3. 伏笔与回收配得上对吗？列出来，落单的是账。
4. 哪一场删掉后，前后仍然接得上？接得上的那一场在为自己服务。
5. 对白八查里，最先破的是哪一条？
6. 这一场怎么演——说不出来的，是写在纸上而不是台上。

结论只说这六项的事实，不替作者改；要改由作者动手。

## 边界

- 材料够不够撑这个故事、该不该做，是动笔之前的判断，不在此。
- 分镜、景别、镜头语言、生成视频的提示词，都在剧本文字之后，不在此。
- 作者亲手写的剧本只提意见，不动原文。
